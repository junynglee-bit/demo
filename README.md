# D-Day Counter

빌드 과정 없이 브라우저에서 바로 동작하는 D-Day 카운터입니다.

## 기능

- 이름과 날짜로 D-Day 추가 / 삭제
- 남은 날은 `D-N`, 당일은 `D-Day`, 지난 날은 `D+N`으로 표시
- **매년 반복**: 생일·기념일처럼 매년 돌아오는 날의 다음 발생일까지 계산 (2/29는 평년에 2/28)
- **시작일을 1일로**: 사귄 날·입사일처럼 시작일을 1일째로 세어 `N일째`로 표시
- 다가오는 일정은 가까운 순, 지난 일정은 최근 순으로 정렬
- `localStorage`에 저장되어 새로고침해도 유지, 자정이 지나면 자동 갱신
- 다크 모드 지원

## 실행

ES 모듈을 사용하므로 로컬 서버로 열어야 합니다.

```bash
npm start            # 또는: python3 -m http.server
```
